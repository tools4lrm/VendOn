# Identificação de Cliente para Fidelidade

**COMO** Operador de caixa,   
**QUERO** vincular o CPF/telefone do cliente ao pedido no momento do fechamento    
**PARA** acumular pontos no programa de fidelidade e registrar seu histórico de consumo.   

**Critérios de Aceitação:**

- Permitir buscar cliente já cadastrado por CPF ou telefone.    
- Caso não exista, permitir um cadastro rápido (Nome, Telefone, CPF).
